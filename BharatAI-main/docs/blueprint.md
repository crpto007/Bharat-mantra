# **App Name**: BharatAI Suite

## Core Features:

- Unified Chatbot: A multilingual AI chatbot supporting English and Indian languages with voice input/output and memory. Connects with other tools as a central hub.
- Grounded Search Tool: Web-integrated AI search to summarize information and cite reliable sources using a tool to choose when it will include information from specific sources.
- Indian Law Explainer: AI to simplify Indian legal acts/clauses in English/Hindi.
- AI Document Generator: Generates basic legal contracts, NDAs, and affidavits; exports as PDF.
- Audio-to-Text: Converts speech to text.
- Prompt Enhancer Tool: Automatically refine user prompts for better output.
- Task Finisher: Refines user notes into action items.

## Style Guidelines:

- Primary color: Saturated indigo (#4F46E5) to evoke intellect, innovation, and productivity.
- Background color: Light gray (#F3F4F6) provides a clean, modern, and calming backdrop.
- Accent color: A vivid orchid (#BE185D) for highlighting important UI elements.
- Body text: 'PT Sans', a clean and readable sans-serif.
- Headline text: 'Space Grotesk' to highlight AI/tech/computer science aspects. If longer text is anticipated, use Space Grotesk for headlines and 'Inter' for body.
- Consistent icon set across all features; use simple, geometric icons with rounded edges to give a friendly yet professional feel.
- Clean and structured layout using a sidebar navigation; maximize screen real estate for main content areas with collapsible sections where appropriate.
